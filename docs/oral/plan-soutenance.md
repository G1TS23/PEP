# Plan de soutenance

Total annoncé : 45 minutes. La durée de présentation est à confirmer avec l'école (voir `docs/guide-livrables-pep.md`). Le déroulé ci-dessous suit la structure recommandée de 30 minutes.

| Temps | Partie | Preuve à montrer | Diapositives |
|---|---|---|---|
| 3 min | Introduction générale | schéma du fil conducteur | |
| 5 min | Livrable 1 : entreprise, SI, premiers constats | cartographie du SI | |
| 7 min | Livrable 2 : mission significative | KPI avant/après, extrait du pipeline | |
| 8 min | Livrable 3 : PEP et amélioration continue | graphique avant/après, cycle PDCA | |
| 4 min | Analyse transversale | tableau des compétences | |
| 3 min | Conclusion | recommandations prioritaires | |

Rappels : ne pas lire ses notes (pénalité), tenir le temps, préparer les questions du jury.
