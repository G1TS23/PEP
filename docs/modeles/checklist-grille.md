# Checklist de relecture avant dépôt

À cocher pour chaque rapport. Les critères viennent des grilles de l'Annexe 1 du PEP.

## Forme
- [ ] Mise en page cohérente, titres numérotés, table des matières.
- [ ] Schémas et tableaux commentés, pas décoratifs.
- [ ] Volume respecté (M1 ~20 p., M2 30 p. hors annexes, M3 ~50 p.).
- [ ] Orthographe relue : les fautes sont pénalisées.

## Fond
- [ ] Pratique réelle décrite, pas de théorie scolaire.
- [ ] Pas de code ni de mode d'emploi dans le corps du texte.
- [ ] Chiffres, durées, volumes dans chaque activité.
- [ ] Chaque choix justifié et comparé à une alternative.
- [ ] Chaque affirmation clé a une preuve.
- [ ] Aucune donnée confidentielle.

## Dépôt
- [ ] Validation du maître d'apprentissage (M1 et M2).
- [ ] Nom de fichier conforme : `EADL_Mission2_Nom_Prenom.pdf`, `EADL_PEP_M3_NOM_PRENOM.pdf`.
- [ ] PDF avec annexes.
