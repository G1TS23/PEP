# Modèle de section

À copier pour chaque section d'un rapport. Une section sans preuve ni chiffre n'est pas terminée.

```markdown
## X.Y Titre explicite

**Contexte (2-3 lignes)** : <à compléter>

**Ce que j'ai fait** : <à compléter>

**Choix et alternatives** : <option retenue, options écartées, critères>

**Preuve** : <capture, log, métrique, KPI avec valeur et date> (figure N, annexe X)

**Résultat chiffré** : <avant> -> <après>

**Limites** : <à compléter>
```
